## The short version

CodeVault is **not a product company**. We run **projects** across everything
in tech — a trial, an experience, an adjustment, a result. Our site should feel
calm, confident, and understated (think Anthropic) with an explorer's stance
(think NASA). Motto: **"We point ourselves at tech, and see what happens."**
